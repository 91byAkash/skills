# Anything else (memo, kickoff note, thank-you, request for input)

Before drafting, settle four things (ask the user if the request doesn't say):
1. **Audience**: who reads it, and what they already know.
2. **Purpose**: inform, ask for a decision, ask for help, or recognise someone.
3. **Tone**: formal, casual, urgent or informational.
4. **Format constraints**: channel, length, house template, who it's sent as.

Then:
- Put the most important information first: the point or the ask in the opening line.
- Use the active voice and plain words, and keep it as short as it can be while staying complete.
- Link to the sources; don't paste them in.
- Match how the organisation already writes. If the user can share a past message that landed well, mirror its length and register.
- End with the next step: who does what, by when.

Check it with `comms_check.py --type general --channel <slack|email|doc>`.
