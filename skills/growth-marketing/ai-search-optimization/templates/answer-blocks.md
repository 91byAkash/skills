# Answer Block Patterns

Each block must make sense if quoted alone. Put the block directly under a heading phrased the way people ask. Keep the opening answer to 40-60 words; voice-style answers under 30 words.

## Definition (for "what is X")
```markdown
## What is [term]?
[Term] is [category/genus] that [what it does / key differentiator]. [1-2 sentences: how it works or main characteristics]. [Why it matters or who uses it, with one specific number or example].
```

## Steps (for "how to X")
```markdown
## How to [goal]
[One sentence: what the process achieves and how long it takes.]
1. **[Step name]**: [action in 1-2 sentences, with the specific setting/value].
2. **[Step name]**: …
3. **[Step name]**: …
[Expected result or common failure to avoid.]
```

## Comparison (for "X vs Y")
```markdown
## [A] vs [B]: [the deciding difference in a few words]
| Criterion | [A] | [B] |
|---|---|---|
| Price (checked [month year]) | | |
| Best for | | |
| [criterion buyers care about] | | |
| [criterion] | | |
**Bottom line**: Choose [A] if [condition]; choose [B] if [condition].
```

## Pros and cons (for "is X worth it", "should I")
```markdown
## Is [X] worth it for [audience]?
[Direct verdict in one sentence with the main condition.]
**Pros**
- **[Benefit]**: [specific evidence]
**Cons**
- **[Drawback]**: [specific evidence and who it affects]
**Verdict**: [who should and who shouldn't].
```

## FAQ (real buyer questions; 50-100 word answers)
```markdown
### [Question in the buyer's words]?
[Direct answer first sentence.] [2-3 sentences of specifics: numbers, limits, links.]
```

## Statistic
```markdown
[Claim]. According to [named source, year], [number with unit and timeframe]. [What it means for the reader.]
```

## Expert quote
```markdown
"[Quote with a concrete point]," says [Name], [Role] at [Organization]. [One sentence of interpretation.]
```

## Evidence sandwich
```markdown
[Claim.]
Evidence:
- [Data point + source + date]
- [Data point + source + date]
- [Data point + source + date]
[Actionable conclusion.]
```

## Self-contained fact (for product facts assistants get wrong)
```markdown
**Does [Brand] [capability]?** Yes. [Brand] [does X] on [plans/platforms] since [date]. [Link to docs.]
```

## Honest buyer's guide entry (emerging brand)
```markdown
### 1. [Category leader]
[What it does best, honestly, and who it fits.]
### 2. [Your product]
[The specific situations where you go further, with proof.]
```
