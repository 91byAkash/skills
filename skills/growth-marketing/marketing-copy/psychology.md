# Buyer psychology and decision models for copy

Use models to explain why a page isn't working and to choose a specific edit. Each entry: what it is → how to use it → how it gets misused. Ethical line: use psychology to make true value easier to see and act on, never to trick (no fake scarcity, hidden costs, confirmshaming, pre-checked add-ons, or invented social proof).

Before applying any model, answer: what behavior do we want? what does the reader believe now? where are they (awareness → consideration → decision)? what blocks the action today? how will we test it?

## Quick picker

| Problem | Try |
|---|---|
| Low conversion | Hick's law, activation energy, motivation × ability × prompt, friction audit |
| Price objections | Anchoring, framing, mental accounting, loss aversion, rule of 100 |
| Low trust | Authority, social proof, reciprocity, pratfall effect, specificity |
| No urgency | Honest scarcity, loss aversion, Zeigarnik effect, present bias |
| Churn | Endowment, switching costs, status-quo bias, peak-end |
| Choice paralysis | Paradox of choice, defaults, decoy, choice architecture |
| Onboarding drop-off | Goal gradient, IKEA effect, commitment and consistency, small wins |
| Growth stalled | Theory of constraints, local vs global optimum, compounding loops |

## Buyer biases and effects

| Model | What it means | Copy/marketing use | Misuse to avoid |
|---|---|---|---|
| Social proof / bandwagon | People follow what similar others do | Counts, logos of look-alike customers, reviews near CTAs, "most teams pick" labels | Inflated counts, fake reviews |
| Authority | Credible experts and institutions persuade | Certifications, expert quotes, press, data from named sources | Borrowed authority that isn't relevant |
| Liking / similarity | We buy from people like us | Customer stories from the reader's role/industry; founder voice | Fake personas |
| Unity | Shared identity ("people like us") | Name the tribe ("for indie agencies") | Excluding or othering |
| Reciprocity | Gifts create a wish to return the favor | Genuinely useful free tools, templates, audits before the ask | Gifts with hidden strings |
| Commitment and consistency | Small yeses lead to bigger ones | Micro-commitments (quiz, first step), public commitments in onboarding | Trapping via sunk cost |
| Foot in the door | Small request first | Free tool → trial → paid | Bait-and-switch |
| Door in the face | Big request first, then a smaller one seems reasonable | Show premium package, then the core | Fake "original" prices |
| Loss aversion | Losses weigh ~2× gains | Frame cost of inaction ("each month you lose ~$4k in missed receipts") | Fear-mongering |
| Anchoring | First number sets the reference | Show the high tier or total value first; compare with the alternative's cost | Fake "was" prices |
| Decoy effect | A clearly inferior option makes the target look better | Tier design (see pricing-and-offers) | Deceptive packaging |
| Framing | Same fact, different frame | "Save $240/year" vs "$20/month"; "98% delivered" vs "2% bounced" | Misleading frames |
| Contrast effect | Judged relative to what's next to it | Before/after, vs-spreadsheet comparisons | Unfair comparisons |
| Scarcity / urgency | Limited things seem more valuable | Real deadlines, real capacity, cohort dates | Fake timers, fake stock |
| Zero-price effect | "Free" is disproportionately attractive | Free trial/tool/shipping as the hook | "Free" with hidden conditions |
| Present bias | Immediate rewards beat later ones | Instant value: "see your first report in 2 minutes" | Hiding long-term costs |
| Status-quo bias | Default is to change nothing | Lower switching effort (migration help); name the cost of staying | Exaggerating risk of staying |
| Default effect | People keep the preset | Sensible defaults (recommended plan, annual toggle shown clearly) | Pre-checked add-ons |
| Paradox of choice | Too many options stall decisions | 3 tiers, one recommended; fewer CTAs | Hiding options people need |
| Hick's law | Decision time grows with number of options | Trim nav, fields, choices per screen | Removing information |
| Goal-gradient | Effort speeds up near a goal | Progress bars, "2 steps left", loyalty stamps prefilled | Fake progress |
| Zeigarnik effect | Unfinished tasks nag | Checklists, "finish setting up" reminders | Nagging dark patterns |
| IKEA effect | We value what we helped build | Let users configure/customize early | Forcing busywork |
| Endowment effect | We overvalue what we own | Trials with real data, "your workspace" language, reverse trials | Holding data hostage |
| Sunk cost | Past investment drives continuation | Show progress made (history, saved work) in save flows | Guilt-tripping |
| Peak-end rule | Experiences judged by peak and ending | Design a delightful first win and a good offboarding | Ignoring the middle entirely |
| Pratfall effect | Small admitted flaws increase trust | "Not for teams over 500 yet"; honest "who it's not for" | Fake humility |
| Mere exposure | Familiarity breeds liking | Consistent presence (retargeting, newsletter, community) | Spammy frequency |
| Availability heuristic | Vivid, recent examples feel likely | Concrete stories and specific numbers | Scare stories |
| Confirmation bias | People favor confirming info | Meet existing beliefs, then extend them | Echoing false beliefs |
| Curse of knowledge | Experts forget what novices don't know | Test copy with outsiders; define terms | |
| Mental accounting | Money is mentally bucketed | Frame as budget they already have ("less than your coffee budget", "replaces a $99 tool") | |
| Regret aversion | Fear of a bad choice delays decisions | Guarantees, easy cancellation, "switch plans anytime" | |
| Fundamental attribution error | We blame people, not situations | Write about the situation that causes the pain, not the reader's failings | Shaming the reader |
| Mimetic desire | We want what admired others want | Show respected customers using it | |
| Lindy effect | Things that have lasted are expected to last | Years in business, longevity of the method | |
| Hyperbolic discounting | Strong preference for now over later | Monthly price framing, instant access | |

## Pricing psychology (see pricing-and-offers for structure)

Charm pricing ($49) signals value; round pricing ($50) signals quality and is processed faster; rule of 100 (under $100 show % off, over $100 show $ off); good-better-best relativity; mental accounting ("$1.60 per user per day"); show annual savings in currency.

## Behavior design models

| Model | Core idea | Use |
|---|---|---|
| Motivation × ability × prompt | Action needs all three at once | High motivation but hard → simplify; easy but no prompt → add a timely trigger |
| EAST | Make it easy, attractive, social, timely | Checklist for any conversion step |
| COM-B | Capability, opportunity, motivation | Can they? Is the path clear? Do they want to? |
| Activation energy | Starting cost blocks action | Lower the first step (templates, sample data, "try without signup") |
| Choice architecture / nudges | How options are presented changes choices | Order, defaults, highlighting; always reversible |
| AIDA | Attention → interest → desire → action | Page narrative check |
| Rule of 7 | Several touches before buying | Plan multi-touch nurture rather than one-shot pages |
| North star metric | One metric capturing delivered value | Align copy promises with the value metric |
| Cobra effect | Incentives can backfire | Check referral and discount incentives for gaming |

## Thinking models for marketers

First principles (rebuild from what customers need, not what competitors do) · jobs to be done · circle of competence · inversion (list how the page would fail, prevent those) · Occam's razor (simplest explanation for a drop first) · Pareto (20% of channels/pages drive 80% of results) · local vs global optimum (button tests vs a new offer) · theory of constraints (fix the biggest bottleneck first) · opportunity cost · diminishing returns · second-order effects (discounts → price-sensitive customers) · map ≠ territory (dashboards aren't customers) · probabilistic thinking (bets with expected value) · barbell (mostly safe bets plus a few bold ones).

## Growth dynamics

Feedback loops and compounding (content, referrals, SEO), network effects, flywheels, switching costs (integrations, data, habits; earn them through value), exploration vs exploitation (keep ~10-20% of effort on new channels), critical mass/tipping points (marketplaces, communities), survivorship bias (study failures and churned users, not just winners).
