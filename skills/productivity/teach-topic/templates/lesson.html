Running totals

Goal: write a running total of signups per day with one window function.

Warm-up

Which clause keeps one row per group and removes the rest?

Example first

SELECT day, signups,
       SUM(signups) OVER (ORDER BY day) AS running_total
FROM daily_signups;
daysignupsrunning_total
Mon44
Tue711
Wed213

What is happening

OVER (ORDER BY day) turns SUM into a window function: every row stays, and each row sums the rows from the start up to itself. That set of rows is the window frame.

Practice

You want a separate running total for each country. What do you add inside OVER?

Your turn: write the full query for running signups per country, then paste it in our chat.

Show one answer (after you try) 
SELECT country, day, signups,
       SUM(signups) OVER (PARTITION BY country ORDER BY day) AS running_total
FROM daily_signups;

Recap

  • Window functions keep every row.
  • ORDER BY inside OVER makes the total run.
  • PARTITION BY restarts it per group.
